# Avlod GPT — настройка ключа API

Avlod GPT использует Supabase Edge Function `avlod-gpt`. Ключ OpenAI хранится только на сервере и не должен попадать в `app.js`, GitHub Pages, чат или клиентские настройки.

## Добавить секрет

1. Открой Supabase Dashboard: https://supabase.com/dashboard/project/yurbyblszgyznaxxtdlb/functions/secrets
2. Создай секрет с именем `OPENAI_API_KEY`.
3. В значение вставь свой API key из https://platform.openai.com/api-keys.
4. Сохрани секрет. Не отправляй сам ключ в сообщения и не добавляй его в репозиторий.
5. Проверь, что в OpenAI API billing/credits настроены для проекта. Подписка ChatGPT сама по себе не включает API-баланс.

## Проверка

- Открой https://tojiev1505-png.github.io/Avlod-web/ и войди в семейный аккаунт.
- Перейди в Avlod GPT и задай вопрос о расходах.
- Без секрета сервер должен возвращать понятную ошибку настройки; после добавления ключа должен появиться ответ.
- Попробуй «Анализ расходов», голосовой ввод и загрузку чека JPEG/PNG/WebP до 4 МБ.
- Не используй настоящие банковские документы для первого теста; начни с тестового чека без чувствительных данных.

## Защита и ограничения

- Edge Function требует авторизованный JWT и проверяет членство в семье.
- Не вставляй OpenAI API key в браузерный код или в публичные GitHub Actions variables.
- Запросы передают модели до 500 последних операций и до 100 целей семьи для анализа.
- Голосовой ввод использует поддержку SpeechRecognition браузера и может быть недоступен в некоторых браузерах.
- AI-ответы и распознавание чеков нужно сверять с оригиналом. Прогнозы — оценки, не гарантии.
