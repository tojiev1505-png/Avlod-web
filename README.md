# Avlod — семейный бюджет

Мобильное веб-приложение (PWA) для учёта семейных доходов, расходов и целей накопления.

## Уже реализовано
- Главная сводка бюджета, история операций и цели накоплений.
- Локальный режим без аккаунта.
- Регистрация и вход через Supabase Auth.
- Создание семейной группы, присоединение по приглашению и обновление данных из облака.
- Сохранение операций и целей в семейном облаке после входа в семейную группу.
- Avlod GPT: чат, анализ расходов, прогноз бюджета, план накоплений и разбор фото чека.
- Голосовой ввод через браузер, если он поддерживается устройством и браузером.
- Установка на Android как PWA через Chrome («Добавить на главный экран» / «Установить приложение»).

## Android
1. Открой сайт в Google Chrome на Android.
2. Открой меню Chrome и выбери «Установить приложение» или «Добавить на главный экран», если доступно.
3. Для обновления закрой приложение, заново открой сайт в Chrome и перезагрузи страницу.

## Настройка Avlod GPT
Функция Supabase Edge Function называется `avlod-gpt`. Для реальных ответов ИИ в Supabase Function Secrets должен быть добавлен секрет `OPENAI_API_KEY`. Ключ OpenAI хранится только на сервере и не должен попадать в `app.js`, GitHub или публичные файлы.
Подробная инструкция: [docs/AVLOD_GPT_SETUP.md](docs/AVLOD_GPT_SETUP.md).

## Безопасность и проверка
- Не публикуй секретные ключи, пароль базы данных или `service_role`.
- Используй реальные финансовые данные только после проверки входа и совместной работы двух отдельных аккаунтов.
- Голосовое распознавание зависит от браузера и системной службы речи; при проблемах используй микрофон клавиатуры Android.
- Очистка данных в профиле очищает локальные данные устройства, а не удаляет семейные записи из облака.
